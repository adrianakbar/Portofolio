# Portfolio React Bits

Portfolio website for **Adrian Akbar Ramadhani** built with:

- Vite + React + TypeScript
- Tailwind CSS v4
- [React Bits](https://reactbits.dev) animated components

## Components used

Aurora, SplitText, BlurText, RotatingText, SpotlightCard, TiltedCard, ScrollReveal, ShinyText, CountUp, Dock, GradientText, TrueFocus, FadeContent, StarBorder, ClickSpark

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
